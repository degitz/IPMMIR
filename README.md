# IPMMIR
Iterative Projection Matching for Multimodal Image Registration
Designed to co-register 3D microCT data with 2D multi-slice MRI data. MRI data was acquired on a 4.7T, 33cm bore research scanner with a Varian INOVA spectrometer. A custom quadrature coil was utilized for data acquisition.
